## Handy Remote

More polish on the remote mobile client and the desktop remote session.

History now keeps a unique audio file per transcription, so playback matches the entry you opened. Streaming chunks stay out of history; finishing a recording finalizes the full audio before reprocess or retranscribe.

## Mobile

- Choose the same post-process prompt you use on desktop
- Sound themes play when recording starts and stops
- Models can be filtered by language, accuracy, and speed
- Portuguese accents render correctly in settings

## Desktop

- Remote Session label fits the sidebar
- Update checks point at this fork
- Remote settings expose prompts and model scores for the phone client
